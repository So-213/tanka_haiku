# 俳句/短歌のAIサイト

ユーザが入力した俳句や短歌に対してAIが感想を返答するアプリケーション


## 初版作成

2024.12


## 制作期間

1ヶ月くらい？


## 機能

フォームに俳句・短歌を入力してボタンを押すとAIが感想を返す


## 技術スタック

- **バックエンド**: Node.js (v22.9.0), Express.js
- **フロントエンド**: HTML, CSS, JavaScript
- **パッケージ管理**: npm
- **ホスティング**: Vercel
- **開発ツール**: v0, Cursor


## 制作理由

Webの勉強を始めて3ヶ月目の頃, V0という非常に便利なツールを知り, V0で何か簡単なものを作ってみたいと考えた結果, 祖母が俳句に夢中になっていたのを見て思いついたのがこのアプリです.
